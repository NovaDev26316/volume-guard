# Volume Guard Privacy Policy for v0.3.0

Volume Guard processes the current active tab audio locally in the browser. Tab audio is not recorded, stored, uploaded, sold, or shared.

Extension settings are saved in the browser's local extension storage.

Bug report diagnostics are optional and are shared only when the user manually copies or submits them to GitHub Issues. Diagnostics may include version, site, active state, gain, input level, output volume, browser, language, and timestamp. Users should remove sensitive information before posting because GitHub Issues may be public.

Volume Guard follows the Chrome Web Store User Data Policy, including Limited Use requirements.
