# Volume Guard Privacy Policy for v0.4.5

## In-app support reports

Volume Guard does not automatically upload diagnostics or support data. The extension sends a support report only after the user reviews the in-app form and presses **Submit report**.

The report may contain the user-entered category, title, description, optional reproduction steps, extension version, language, status, opaque public report ID, and timestamps. Diagnostics are optional and use a strict whitelist: extension and manifest version, browser summary and language, UI language, active state, current gain, input level, output volume, normalization strength, Night Mode state, scope, and plan. The current site hostname is a separate opt-in.

Reports do not include raw audio, full URLs, page titles, saved-site hostname lists, access or refresh tokens, OTPs, device/session secrets, email or client-supplied user IDs, Lemon Squeezy customer or subscription IDs, payment data, or arbitrary Chrome storage. A valid signed-in request may be associated with the authenticated account. Anonymous submission is supported.

Support reports are stored so operators can review recent reports and update their status through private backend tooling. The default report retention period is 180 days, after which backend cleanup deletes the report. Encrypted backups follow a separate rolling retention cycle. The support endpoint may process IP addresses for abuse prevention; its current MVP limiter is process-local and resets on restart.

For access or deletion questions, contact `novadev26316@gmail.com` privately. Do not post personal data or security vulnerabilities in public GitHub Issues. Security reports must follow [`SECURITY.md`](../SECURITY.md).

## 개인정보 처리방침 요약

v0.4.5의 인앱 지원 신고는 자동 전송되지 않습니다. 사용자가 내용을 확인하고 **신고 제출**을 누른 경우에만 전송됩니다. 진단 정보는 선택 사항인 whitelist 항목이며, 현재 사이트 호스트명은 별도 허용한 경우에만 포함됩니다. 원본 오디오, 전체 URL, 토큰·OTP·결제 정보, 고객·구독 식별자와 임의의 Chrome storage는 포함되지 않습니다.

로그인된 유효한 세션으로 제출한 신고는 계정과 연결될 수 있고, 익명 제출도 가능합니다. 운영자는 비공개 backend tooling으로 최근 신고와 상태를 확인합니다. 기본 신고 보존 기간은 180일이며 이후 삭제하고, 암호화 백업은 별도 순환 주기로 만료됩니다. 악용 방지를 위해 IP가 처리될 수 있습니다.
