# Volume Guard Privacy Policy for v0.2.9

Volume Guard processes the current active tab audio locally in the browser. Tab audio is not recorded, stored, uploaded, sold, or shared.

Extension settings are saved in the browser's local extension storage. These settings may include presets, output volume, site exclusions, language settings, active state, gain, and related audio preferences.

Bug report diagnostics are optional. They may include version, site, active state, gain, input level, browser, language, timestamp, and details the user writes in a GitHub Issue. Volume Guard does not automatically send bug reports. Users should remove sensitive information before submitting a public GitHub Issue.

Volume Guard's use of information received from Chrome extension APIs follows the Chrome Web Store User Data Policy, including Limited Use requirements.
