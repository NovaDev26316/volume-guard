# Volume Guard Privacy Policy for v0.2.8a

This document describes the privacy behavior of **Volume Guard Normalizer v0.2.8a**. It is a version-specific Markdown companion to the official HTML privacy policy in this repository.

## Summary

Volume Guard Normalizer processes the current active tab audio locally in the browser using Chrome extension APIs and the Web Audio API. The extension does not record, store, upload, sell or share tab audio.

## Active tab audio

When the user enables Volume Guard, the extension may capture the audio stream from the currently active tab to apply local volume normalization and output volume adjustment.

The captured tab audio is processed locally in the user's browser. Volume Guard does not:

- record tab audio;
- save tab audio;
- upload tab audio to external servers;
- sell tab audio;
- share tab audio with third parties.

## Extension settings

Volume Guard stores extension settings in the browser's local extension storage. These settings may include presets, output volume, site exclusions, language settings, enabled or disabled state, gain and related audio-control preferences.

These settings are used only to provide the extension's audio normalization and control features.

## Optional diagnostics for bug reports

Volume Guard does not automatically send bug reports or diagnostics.

If a user chooses to report a bug, the user may manually copy diagnostics from the extension or open a GitHub Issue draft. Diagnostics may include:

- extension version;
- site or tab URL/domain entered into the report template;
- active state;
- gain;
- input level;
- output volume;
- browser information;
- language;
- timestamp;
- other details the user manually writes in the GitHub Issue.

This diagnostic information is shared only when the user manually copies it, pastes it, or submits it to GitHub Issues.

GitHub Issues may be public. Users should remove personal, private or sensitive information before submitting an issue.

## Chrome Web Store Limited Use disclosure

Volume Guard's use of information received from Chrome extension APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Data accessed through Chrome extension APIs is used only to provide or improve the extension's single-purpose audio normalization functionality.
