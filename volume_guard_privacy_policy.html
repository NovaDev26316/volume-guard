Volume Guard Privacy Policy

Effective date: 2026-06-18

Volume Guard is a Chrome extension that helps normalize and control audio volume for the active browser tab.

Data handled by Volume Guard

1. Website content: active tab audio

When the user activates Volume Guard, the extension may capture the audio stream of the currently selected active tab in order to apply local volume normalization and output volume adjustment.

The captured tab audio is processed locally in the browser. Volume Guard does not record, store, upload, sell, or share tab audio.

2. Extension settings

Volume Guard may store user preferences locally in the browser, such as normalization strength, output volume level, selected preset, and enabled or disabled state.

These settings are used only to provide the extension’s audio control features.

Data Volume Guard does not collect

Volume Guard does not collect personal identification information, health information, financial or payment information, authentication information, personal communications, location data, browsing history, or user activity logs.

Data sharing

Volume Guard does not sell user data. Volume Guard does not transfer user data to advertising platforms, data brokers, or information resellers. Volume Guard does not use user data for personalized advertising. Volume Guard does not use user data to determine creditworthiness or for lending purposes.

Remote processing

Volume Guard processes tab audio locally in the browser. Tab audio is not transmitted to external servers.

Data retention

Extension settings remain stored locally in the user’s browser until the user changes the settings, resets the extension, or uninstalls the extension.

Chrome Web Store Limited Use disclosure

The use of information received from Chrome extension APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.
