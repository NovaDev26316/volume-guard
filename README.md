# volume-guard
Official public hub for Volume Guard — feedback, bug reports, release notes, and privacy policy.

Volume Guard is a Chrome extension for managing and controlling browser audio.

This is the official public repository for Volume Guard.

> This repository is used for support, feedback, release notes, and public documentation.
> The Volume Guard extension source code is not published in this repository.
