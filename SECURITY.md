# Security Policy

## Reporting a Vulnerability

Do not report security vulnerabilities through public GitHub Issues. Public issues may expose sensitive vulnerability details before they can be addressed.

Report vulnerabilities privately by email to `wnsdud040820@gmail.com`.

Include the following information when it is relevant:

- the affected Volume Guard version;
- clear reproduction steps;
- the potential impact;
- a proof of concept, if appropriate; and
- relevant operating system, browser, browser version, and environment details.

Do not include unnecessary personal data, credentials, private browsing information, or other unrelated sensitive information in a security report.

This repository does not operate a bug bounty program.
